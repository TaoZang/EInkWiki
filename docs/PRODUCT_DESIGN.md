# 墨水维基 MVP 产品设计

## 1. 产品目标

让网络条件不稳定、刷新较慢的 Android 墨水屏设备，能够完成一个清晰的闭环：

```text
安装轻量 APK → 电脑浏览器上传 ZIM → 指定搜索库 → 输入关键词 → 查看结果 → 阅读完整条目
```

首版只读，不提供账号、编辑、讨论、通知或内容同步。应用不提供内容下载目录；只有用户主动启动局域网导入或手动检查应用更新时使用网络，搜索与阅读完全本地完成。

## 2. 信息架构

### 首页

- 应用默认进入极简首页，关键词输入框固定居中
- 从当前 ZIM 随机显示三个条目，并按固定低频间隔更新
- 用户提交关键词后进入离线搜索结果页，不做逐键查询
- 右上角“书库”进入 ZIM 导入、选择、删除与应用更新管理

### 离线书库

- 点击导入后在设备上启动临时 HTTP 文件服务，显示同一局域网内可访问的网址
- 电脑浏览器选择任意 `.zim`，分块上传并显示整数进度、容量与实时速度
- 中断后重新选择同名、同大小文件可继续传输；一次只接收一个文件
- 完成后只检查 ZIM 结构可读性，不查询目录，不计算远端哈希
- 多个 ZIM 可以共存，内存中一次只打开一个当前搜索库
- 用户动作只有：启动/停止导入、设为搜索库、开始搜索、删除
- 局域网导入期间保持屏幕常亮，停止导入后恢复系统休眠

### 搜索

- 用户输入后显式提交搜索，不做逐键实时请求，减少墨水屏刷新
- 优先使用 ZIM 全文索引，结果包含标题和纯文本摘要
- 无全文索引时回退到标题索引
- 一次最多显示 50 条，首版不做无限滚动动画

### 阅读

- 条目 HTML、样式、字体和静态图片均从 ZIM 内读取
- 内部条目链接继续留在本应用；外部链接在离线模式下阻止并提示
- 正文使用黑字白底、内置 Noto Serif SC、较大行距；标题使用相同字族和较小字号差
- 提供上一页、下一页、字小、字大四个明确操作
- 阅读正文时保持屏幕常亮，离开正文后恢复系统休眠策略
- 支持 Page Up/Down、音量上下、左右方向和 Navigate Previous/Next 实体翻页键

## 3. 墨水屏约束

- 不使用 Compose、Activity 转场、属性动画、涟漪、阴影、渐变、骨架屏或平滑滚动
- 下载状态与速度最多每 3 秒更新一次，并只重绘发生变化的活动行
- 搜索不随每个按键刷新，结果列表无缩略图
- WebView 关闭 JavaScript、DOM Storage、数据库、缩放控件和媒体
- CSS 强制 `animation: none`、`transition: none`、`scroll-behavior: auto`
- 翻页使用一次性整数距离 `scrollBy`，保留少量上下文重叠
- 不调用厂商私有刷新 API；后续可用独立适配层支持文石、掌阅等设备

## 4. ZIM 导入生命周期

```text
WAITING → RECEIVING → FORMAT_CHECK → READY
                    ↘ INTERRUPTED → RESUME
```

1. 浏览器提供文件名与总字节数
2. 顺序写入同名 `.zim.partial`，每个分块返回当前偏移
3. 断线后用临时文件长度作为续传位置
4. 收满后用 libzim 打开并读取一个条目
5. 同目录重命名为 `.zim`，之后才对搜索页可见

正式文件和临时文件不会混用。应用不判断文件内容来源，也不进行 MD5/SHA 校验。删除操作只针对书库中的单个精确路径。

## 5. 技术选择

- Android API 24+，经典 Java Views
- 单 Activity、四个即时切换的 View 状态，消除页面转场
- 内嵌最小 HTTP 服务 + 浏览器分块 PUT：无需 ADB 或电脑端专用程序
- 应用专属 external files：无需广泛存储权限
- `org.kiwix:libkiwix:2.6.0`：OpenZIM 读取、全文索引和标题建议
- WebView 自定义资源拦截：所有内容从 `https://zim.local/` 虚拟源读取

## 6. MVP 后续

1. 增加用户选择存储卷、剩余空间预估和 FAT32 大文件提示
2. 支持 SAF 直接导入和分卷 ZIM
3. 增加目录、页内查找、阅读位置恢复和横竖屏排版偏好
4. 在真实墨水屏设备上测量局刷残影、首屏时间、翻页耗时和内存峰值

不进入首版的范围：在线 Wikipedia API 回退、账号系统、编辑、收藏同步、TTS、视频、动态主题和推荐流。
