# 墨水维基 MVP 产品设计

## 1. 产品目标

让网络条件不稳定、刷新较慢的 Android 墨水屏设备，能够完成一个清晰的闭环：

```text
安装轻量 APK → 选择并下载 ZIM → 指定搜索库 → 输入关键词 → 查看结果 → 阅读完整条目
```

首版只读，不提供账号、编辑、讨论、图片上传、通知或内容推荐。只有用户进入书库更新目录、明确下载离线包或手动检查应用更新时才联网；搜索与阅读完全本地完成。

## 2. 信息架构

### 首页

- 应用默认进入极简首页，正文区域只放一个关键词输入框
- 用户提交关键词后进入离线搜索结果页，不做逐键查询
- 右上角“书库”进入离线包与应用更新管理

### 离线书库

- 从 Kiwix OPDS v2 目录展示全部当前中文 Wikipedia 包，并在失败时回退到缓存/内置目录
- 展示包名、主题、内容类型、版本、准确大小、文章数和来源
- 状态只有：未下载、等待、下载中、暂停、校验中、可阅读、失败
- 下载中展示整数进度、已下载容量和按固定间隔采样的实时速度
- 用户动作只有：下载、取消、重试、设为搜索库、开始搜索、删除
- 多个包可以共存，但一次只允许一个下载/校验任务，内存中也只打开一个搜索库
- 首个校验成功的包自动成为搜索库；之后下载新包不会擅自切换用户选择
- 书库存在活动下载时保持屏幕常亮，下载结束、失败、取消或离开书库后恢复系统休眠

### 搜索

- 用户输入后显式提交搜索，不做逐键实时请求，减少墨水屏刷新
- 优先使用 ZIM 全文索引，结果包含标题和纯文本摘要
- 无全文索引时回退到标题索引
- 一次最多显示 50 条，首版不做无限滚动动画

### 阅读

- 条目 HTML、样式、字体和静态图片均从 ZIM 内读取
- 内部条目链接继续留在本应用；外部链接在离线模式下阻止并提示
- 正文使用黑字白底、衬线字体、较大行距；标题使用无衬线字体
- 提供上一页、下一页、字小、字大四个明确操作
- 阅读正文时保持屏幕常亮，离开正文后恢复系统休眠策略
- 支持 Page Up/Down、音量上下、左右方向和 Navigate Previous/Next 实体翻页键

## 3. 墨水屏约束

- 不使用 Compose、Activity 转场、属性动画、涟漪、阴影、渐变、骨架屏或平滑滚动
- 下载状态与速度最多每 3 秒更新一次，并只重绘发生变化的活动行
- 搜索不随每个按键刷新，结果列表无缩略图
- WebView 关闭 JavaScript、DOM Storage、数据库、缩放控件和媒体
- CSS 强制 `animation: none`、`transition: none`、`scroll-behavior: auto`
- 翻页使用一次性整数距离 `scrollBy`，保留少量上下文重叠
- 不调用厂商私有刷新 API；后续可用独立适配层支持文石、掌阅等设备

## 4. 离线包生命周期

```text
QUEUED → DOWNLOADING → VERIFYING → READY
                   ↘ FAILED → RETRY
```

1. 从 OPDS 获取目录项，再从官方 `.meta4` 冻结精确文件名、字节数和 SHA-256
2. 下载到版本化 `.zim.partial`
3. 检查准确字节数
4. 流式计算 SHA-256
5. 用 libzim 打开并读取一个条目
6. 同目录重命名为 `.zim`
7. 保存已校验哈希和不可变描述快照，之后才对搜索页可见

正式文件和临时文件不会混用。删除操作只针对清单中计算出的单个精确路径。更新全量中文包时需保留新旧两份空间，确认新包可读后再切换。

## 5. 技术选择

- Android API 24+，经典 Java Views
- 单 Activity、四个即时切换的 View 状态，消除页面转场
- 系统 `DownloadManager`：跨进程下载、网络变化重试、系统通知
- Kiwix OPDS v2 + Metalink 4：动态中文包目录与精确下载完整性元数据
- 应用专属 external files：无需广泛存储权限
- `org.kiwix:libkiwix:2.6.0`：OpenZIM 读取、全文索引和标题建议
- WebView 自定义资源拦截：所有内容从 `https://kiwix.local/` 虚拟源读取

## 6. MVP 后续

1. 增加用户选择存储卷、剩余空间预估和 FAT32 大文件提示
2. 支持 SAF 导入现有 ZIM 与分卷 ZIM
3. 对同一内容系列提供“有新版”提示和确认后的整包替换流程
4. 增加目录、页内查找、阅读位置恢复和横竖屏排版偏好
5. 在真实墨水屏设备上测量局刷残影、首屏时间、翻页耗时和内存峰值

不进入首版的范围：在线 Wikipedia API 回退、账号系统、编辑、收藏同步、TTS、视频、动态主题和推荐流。
